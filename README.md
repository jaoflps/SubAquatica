# SubAquatica

Jogo 2D em pixel art feito com Pygame. Explore cinco zonas oceanicas, colete artefatos, evite criaturas territoriais que perseguem o mergulhador e gerencie o oxigenio do traje.

## Executar

No terminal, dentro desta pasta:

```powershell
py -m pip install -r requirements.txt
py main.py
```

## Controles

- `WASD` ou setas: mover
- `Enter`: iniciar, avancar e confirmar
- `H`: tela de ajuda
- `Esc`: voltar ao menu durante uma partida

Ao limpar uma zona, retorne ao submarino no topo da tela. Na estacao entre zonas, compre melhorias com os creditos coletados. A Zona Abissal fica quase totalmente escura e exige duas melhorias de lanterna para ser acessada.
