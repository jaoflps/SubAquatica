# Assets de SubAquatica

Os sprites `diver.ppm` e `anglerfish.ppm` foram criados para este projeto em pixel art 8x8. O preto e' usado como transparencia. As versoes finais do mergulhador, cinco especies de criaturas, corais, minerais e artefatos sao desenhadas em tempo real pelo Pygame com mapas de pixels e paletas originais. Isso permite variacoes de profundidade, iluminacao e cavernas sem depender de imagens de terceiros.
